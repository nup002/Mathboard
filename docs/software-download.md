# Software
Mathpad requires software to work on certain operating systems.

## Mathpad Service
`Mathpad Service` for Macs. It is a small application that runs silently in the background and enables
your Mac to understand the Unicode symbols that Mathpad sends to it.

## WinCompose
`WinCompose` is a small tray application that enables Unicode compose functionality
on Windows. It is available from
[here](https://github.com/samhocevar/wincompose/releases/download/v0.9.11/WinCompose-Setup-0.9.11.exe).
