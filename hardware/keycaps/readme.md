# Keycaps

This folder contains the design files required to create the keycaps.

Symbol keycaps
-----------
The symbol keys use JWA keycap profiles. These can be purchased online or 3D printed using `cad files\JWA-1u.stl`. 
The decals are located in the `decals` folder and must be UV-printed onto the keycaps.

Modifier keycaps
-------------
The bottom modifier switches use 1.5u JWA keycap profiles. These must be 3D printed using `cad files\JWA-1-5u.stl` and `cad files\JWA-1-5u-rounded.stl`.

Mode switch keycap
------------------
The mode switch keycap consist of two pieces that click together: `cad files\JWA-1u-Mode-Switch.stl` and `cad files\Mode-Switch-Insert.stl`.
