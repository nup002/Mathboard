Mathpad enclosure
#################

This folder contains all design files for the enclosure of the Mathpad. 

CAD files of the enclosure in `.step` format are located in the folder `cad files`.

Laser engraving files are located in the folder `laser engraving`.

Specifications for the manufacturing of the enclosure:
	- Material		: Aluminium 6061 or similar
	- Surface 		: As machined
	- Finish  		: Matte black anodization with laser marking
	- Tapped holes  : 4 M2x0.4
	- Tolerances	: ISO2768 medium
