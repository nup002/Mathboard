# Mathpad enclosure

This folder contains all design files for the aluminum enclosure of the Mathpad. 

CAD files are provided in `.step` format and are located in the folder `cad files`.

Laser engraving files are provided in `.svg` format and are located in the folder `laser engraving`.

## Manufacturing specifications
- Material	: Aluminium 6061 or similar
- Surface 	: As machined
- Finish  	: Matte black anodization with laser marking
- Tapped holes  : 4 M2x0.4
- Tolerances	: ISO2768 medium
