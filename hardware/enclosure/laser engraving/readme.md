# Laser engraving

This folder contains the file `mathpad_laser_engraving_back.svg` which is used to perform laser engraving of the 
symbols, labels, and other features on the back of the Mathpad.

The folder `enclosure outlines` contain SVG files of the outline of the Mathpad as seen from the top and the bottom, 
and can be used for developing new laser engraving designs.
